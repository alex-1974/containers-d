# v0.2.0 release performance qualification

The v0.2.0 public API is frozen at
`767e40e1ce838e1fbd75611e408fec502214ab16`
(`freeze/api-0.2.0`).

This release pass does not change the frozen public API. It reruns the
performance probes that established the accepted implementation families on
the release line.

## Qualified families

### StaticRingBuffer

Run `Static Ring Hotfix Performance`.

The probe checks semantic equivalence and retired instructions against the
released v0.1 baseline and C++ reference forms on DMD 2.111, DMD 2.113, and
LDC 1.41.

### RingBuffer

Run `Runtime Ring Buffer Operation Probe`.

The probe covers index, push/pop, segment, and mixed FIFO workloads across
power-of-two and non-power-of-two capacities on DMD 2.111 and LDC 1.41.

### StaticVector

Run `StaticVector Expansion Algorithm Probe`.

The probe compares the production vector against the consumer-local baseline
for a representative geometry expansion workload on DMD 2.111 and LDC 1.41.

### ScratchBuffer

Run both `ScratchBuffer Reuse Performance` and
`ScratchBuffer Consumer Shapes`.

The reuse probe requires exact retired-instruction parity with the manual
retained-capacity baseline. The consumer-shape probe covers DCanvas-like,
geometry-like, and OSM/raster-like workloads and rejects a candidate more than
10% slower than the manual equivalent.

### WorkStealingDeque

Run `Work-Stealing P08e Parity` and
`Work-Stealing Native AArch64 Performance`.

The first probe compares production against the pinned P08e reference on DMD
2.111 and LDC 1.41. The native AArch64 probe rejects a persistent paired median
ratio above 1.10 on the selected physical-core contention matrix.

### BlockingQueue

Run `BlockingQueue Release Performance`.

The release probe uses the production `BlockingQueue!T` API and compares it
with the same-semantics manual Mutex/Condition bounded FIFO. It covers
capacities 1, 16, and 256 with 1P1C, 2P1C, 1P2C, and 2P2C topologies on native
x86_64 and AArch64 under LDC 1.41. Any paired-median production/manual ratio
above 1.25 fails the release qualification.

The broader M7 synchronization-cost and close/wake-all evidence remains
retained on research PR #62. The production release probe intentionally uses
only public API and does not reintroduce research-only waiter instrumentation.

## Acceptance

The performance qualification is complete only when every workflow above is
green on the exact release-performance PR head. A pushed fix resets the
qualification for the affected head.
